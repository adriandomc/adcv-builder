# ADCV Builder

Personal YAML-first visual resume builder with SvelteKit, Effect, and SCSS. Data is saved directly in your browser's local storage.

## Setup

```sh
npm install -g pnpm
pnpm install
cp .env.example .env
pnpm dev
```

Open `http://localhost:5173`.

## Scripts

- `pnpm dev` starts SvelteKit.
- `pnpm check` runs Svelte and TypeScript checks.
- `pnpm test` runs Vitest.
